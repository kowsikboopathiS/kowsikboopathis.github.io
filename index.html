Projects

GSM-Based Remote Motor Starter for Agricultural Pump

An SMS-controlled starter for a 5HP farm motor, so it can be started and stopped without being at the field.

A programmable timer runs scheduled irrigation cycles automatically. Voltage sensors watch the 3-phase supply, and the system reports power conditions by SMS for safer operation.

  • ESP32
  • GSM module
  • Relay module
  • Voltage sensors

IoT-Based Smart Door Lock System

A secure, web-controlled door lock. MicroPython on an ESP32 handles Wi-Fi connectivity, user commands and servo actuation.

I designed the circuit schematics, built hardware testbenches to evaluate performance and reliability, and tested the full setup end to end for consistent, secure remote operation.

  • ESP32
  • MicroPython
  • Servo motor
  • Wi-Fi

Dual-Mode IoT Smart Water Management System

A microcontroller system that switches between rainwater harvesting and diversion control, and biological contamination monitoring using headspace gas-analysis sensors to evaluate water quality.

I designed the mode-switching logic and sensor integration architecture for autonomous, low-intervention operation, then programmed and tested it for accurate sensing and reliable control.

  • Microcontroller
  • Gas sensors
  • Mode-switching logic
